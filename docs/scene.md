# 场景说明

场景根据 `场地照片/任务场地.jpg` 重建，采用官方量子一号机器人模型，器材以几何模型表示。

## 坐标与布局

单位为米和弧度，Z 轴向上。初始机器人的机械臂前伸方向为 +X。

每张桌的短边沿 X、长边沿 Y，两张桌沿 X 前后排列。四色瓶在近端托盘中，量筒放在另一张桌侧的托盘内。地面路径和底盘轮廓展示绕桌角与转向停靠的空间关系。

`table.join` 控制桌面数量、分割轴和接缝间距。桌高、托盘尺寸与中心、瓶子和量筒尺寸等统一保存在 `simulation/scene_config.json`。

## 查看

离线查看页支持照片视角、全景、俯视、瓶子和量筒五种预设视角，也可拖动旋转、滚轮缩放和右键平移。

四色按钮用于高亮对应瓶子；开关可显示或隐藏机器人、标注、网格、坐标轴和路径示意。布局调整可导出 JSON。

## 精度

单张照片不足以确定绝对尺寸。当前单桌约 0.60 × 1.20 m、桌高 0.75 m，均待现场测量。机器人展示姿态、约 90° 的停靠朝向差和路径属于布局示意。
